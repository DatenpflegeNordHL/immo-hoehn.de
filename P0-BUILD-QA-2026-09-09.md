## 9. Vor P0-Build-Freigabe zwingend

Auf einer Netzwerk-/Repo-fähigen Umgebung ausführen:

```bash
nvm use
npm install
npm run build
```

Danach prüfen:

- keine Astro/Vite-Compilefehler
- erzeugte statische Routen vollständig
- `sitemap-index.xml` / `sitemap-0.xml`
- Canonicals
- noindex-Status im Staging
- interne Links
- Assets
- responsive Layouts 360 / 390 / 412 / 430 / 768 / 820 / 1024 / 1280 / 1440 / 1920
- Lighthouse / CWV

Danach `package-lock.json` committen, damit der Build reproduzierbar wird.
